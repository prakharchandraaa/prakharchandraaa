## 🙋‍♂️ About Me

- 🎓 **Education**: Pursuing **B.Tech in Computer Science & Engineering (2024–2028)** at **United College of Engineering & Research (UCER)**, Prayagraj.
- 💡 **Core Expertise**: Full-Stack Web Development, AI Assistants, RAG & Vector Search, API Architecture, and Modern UI Design.
- 🚀 **Featured Innovation**: Lead Developer of **UCER AI Chatbot v2.0** — an Apple-styled AI assistant powered by LLaMA 3.3 70B (Groq), Sentence Transformers, Flask, and React.

</div>
