## 🏆 Featured Project

<div align="center">

### 🤖 [UCER AI Chatbot v2.0](https://github.com/prakharchandraaa/COLLEGE_CHATBOT)
*Apple-style AI-powered assistant for United College of Engineering & Research, Prayagraj.*

</div>

- ⚡ **LLM Architecture**: Powered by Groq LPU + LLaMA 3.3 70B model with sub-second response times.
- 🧠 **Contextual Embeddings**: Semantic vector matching with `sentence-transformers` (MiniLM).
- 🎨 **Apple Design**: Frosted glass navbar, light/dark mode, typing indicators, copy buttons, speech synthesis, and 5-tab admin dashboard.
